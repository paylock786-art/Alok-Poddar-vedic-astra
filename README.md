# VEDIC ASTRA
**Advanced Vedic Astrology Intelligence System**  
Ancient Wisdom. Astronomical Precision. Intelligent Analysis.

Standalone native Android app. This repository is independent of all Vionex CRM repositories, databases, services and build pipelines.

## Current milestone
Milestone 0: Android foundation and module dashboard. This is a starter application, not yet a complete astrology product. The calculation engines, ephemeris validation, AI image analysis and prediction verification are future milestones.

## Included
- Kotlin + Jetpack Compose Android shell
- Minimum Android 9 (API 28)
- Dashboard modules for Vedic astrology, Mithila Panchang, numerology, palmistry, tarot, Samudrika/face traditions, remedies/puja, time analysis and prediction verification
- Hindi, Maithili and English starter UI strings
- User-facing limitations notice

## Build
Open in Android Studio with JDK 17. Sync Gradle and run the app on Android 9+.
A clean build must be run before considering this milestone verified.

## Independence
Do not add this project to any Vionex CRM repository. All app code, builds and releases belong here.
